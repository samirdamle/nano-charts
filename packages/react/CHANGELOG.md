# @samirdamle/nano-charts-react

## 0.1.0

Initial release: React components for the nano-charts core — `LineChart`, `AreaChart`, `BarChart`, `WinLossChart`, `BulletChart`, `DonutChart`, `ScatterChart`, `HeatmapChart`.

- `onPointHover` / `onPointClick` interactivity on every chart.
- Next.js App Router support (`'use client'` boundaries preserved).
- React 18+ peer dependency; zero other runtime dependencies.
- Per-chart subpath imports, matching the core package.
